# 人体手册 · The Human Body Handbook — Starter Kit

通识线手册系列 · 生命故事视角的人体科普电子书。

## 包内容

| 文件 | 用途 |
|---|---|
| `CLAUDE.md` | 构建约定：技术规格、栏目标配、风格红线。**先读这个。** |
| `OUTLINE.md` | 全书骨架：序章 + 四幕 25 章 + 终章，含每章要点/图表/规格表/前沿/历史锚点 |
| `QUALITY.md` | 系列批量生产质量协议（自 AI 系统手册项目提炼）+ 本书专属检查项 |
| `sample/ch08-birth.html` | **已验收的样章（v2）**——口吻、格式、视觉、交互的唯一基准 |

## 建议构建顺序

1. 通读 CLAUDE.md 与样章，抽取共享 CSS 至 `assets/style.css`
2. 建 `index.html`（导读 + 四幕地图）与章节导航骨架
3. 先产 2 章（序章 + 第 1 章）自检口吻是否与样章一致，再进入批量
4. 每完成一幕跑一次 QUALITY.md 的横切检查；全部完成后做发布前全站审计
5. 部署至 GitHub Pages（与前作同流程）
